# 每日五行穿搭规则（模型无关版）

> 本文档是"个人工作台"的穿搭数据生成规范。
> 任何 AI 模型阅读本文档后，均可按规范生成当日穿搭数据。
> 数据输出为 JSON 格式，写入 `data/today.json` 的 `outfit` 字段。

---

## 一、用户档案

- 性别：女士
- 喜用神：**火、木**（五行中对自身运势有利的元素）
- 所在城市：武汉（亚热带季风气候）
- 穿搭习惯：黑白基础 + 一件出彩单品 / 全身同色系
- 日常活动：学术写作（论文）

## 二、每日数据来源

生成穿搭方案前，需要获取两项实时数据：

### 1. 天气
- 城市：武汉
- 数据来源（任选其一）：
  - 中国气象局：https://weather.cma.cn/web/weather/57494.html
  - 任意可靠的天气 API 或搜索
- 需要字段：最低温、最高温、天气状况、特殊预警（雨/高温/大风等）

### 2. 干支与五行
- 查询今日干支（天干+地支，如"癸丑"）
- 日五行属性（金/木/水/火/土）
- 冲煞（如"冲羊煞东"）
- 吉凶（黄道/黑道）

## 三、五行配色逻辑

### 五行-颜色对应表

| 五行 | 颜色 | 示例 |
|------|------|------|
| 金 | 白、银灰、浅金 | 米白、珍珠白、香槟色 |
| 木 | 绿、青 | 森林绿、橄榄绿、薄荷绿 |
| 水 | 黑、深蓝、牛仔蓝 | 纯黑、藏蓝、牛仔色 |
| 火 | 红、粉、橙、紫 | 珊瑚粉、西瓜红、砖红 |
| 土 | 黄、棕、咖、裸色 | 卡其、驼色、焦糖 |

### 生克关系（核心判断依据）

```
相生：木→火→土→金→水→木（循环相生，助力）
相克：木克土、土克水、水克火、火克金、金克木（克制，消耗）
```

### 穿搭色彩决策树

1. **日五行 = 火或木**（与喜用神同气）
   → 主推：火色系 / 木色系（同气共振，能量最强）
   → 基础色：看白色和黑色当日状态

2. **日五行 = 土**
   → 主推：火色系（火生土，我生者为食伤，付出有收获）
   → 白色可用（土生金，大环境生你，为贵人色）

3. **日五行 = 金**
   → 主推：土色系（土生金）或火色系（火克金，我克者为财，需努力但可得）
   → 优先喜用神火，其次土

4. **日五行 = 水**
   → 主推：木色系（水生木，我生者为食伤）或火色系（水克火，我克者为财）
   → 黑色/牛仔（水属性）当日为同气，可放心穿
   → 白色 ❌（金生水，泄你能量）

### 黑/白/牛仔当日判断规则

**黑色/牛仔（水属性）：**
- 日五行为火 → ❌ 水克火，大面积不宜，仅限 <10% 配饰
- 日五行为土 → ❌ 土克水，不利色
- 日五行为水 → ✅ 同气，可放心穿
- 日五行为木 → ✅ 水生木，助力喜神
- 日五行为金 → ⚠️ 金生水泄气，小面积可穿（<30%）

**白色/银灰（金属性）：**
- 日五行为木 → ❌ 金克木，消耗喜神，不宜大面积
- 日五行为火 → ⚠️ 火克金，小面积可（<30%）
- 日五行为土 → ✅ 土生金，贵人色，大面积可用
- 日五行为金 → ✅ 同气
- 日五行为水 → ❌ 金生水，泄你能量

## 四、季节与面料适配

根据当日气温自动判断：

| 季节 | 气温 | 面料建议 |
|------|------|---------|
| 春（3-5月） | 15-25°C | 纯棉、薄羊毛、混纺 |
| 夏（6-8月） | >25°C | 亚麻、真丝、薄纯棉、冰丝、雪纺 |
| 秋（9-11月） | 15-25°C | 纯棉、羊毛、混纺 |
| 冬（12-2月） | <10°C | 羊毛、羊绒、加厚棉、羽绒 |

温差 ≥8°C 时提醒"备一件薄开衫/外套"。
有雨时提醒"携带雨具，鞋选防滑款"。

| `special_notes` | 当日特别提醒（温差、冲煞、UV、湿度等） |

## 六、每日一句（quote）

生成穿搭数据时，同时生成一句与当日意境匹配的话：

```json
"quote": {
  "text": "一句与当日五行/天气/季节意境匹配的话（30字以内）",
  "source": "出处（如有）"
}
```

**生成原则：**
- 结合当日五行元素（如：水日→与水相关的哲理；木日→生长/萌发；火日→热情/能量）
- 结合当日天气（晴→明朗/开阔；雨→静思/沉淀；阴→内敛/蓄力）
- 可引用经典（道德经/论语/诗词），也可以是原创一句话
- 语气：温暖、简短、有力量，不说教
- 30 字以内为宜

## 七、执行频率

- **每天一次**，建议清晨执行（05:00-07:00）
- 生成后写入 `data/today.json`
- 同日不可重复生成（避免覆盖当日已推送内容）
