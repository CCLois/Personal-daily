# 每日复盘规则（模型无关版）

> 本文档定义"晚间复盘"的数据生成规范。
> 任何 AI 模型阅读本文档后，均可按规范生成当日复盘数据。
> 输出写入 `data/today.json` 的 `review` 字段。

---

## 触发时机

每天 21:00（或用户指定时间），生成当日复盘。

## 复盘内容

### 1. 今日回顾
- 今日穿搭方案是否已推送？推送时间？
- 今日天气实况 vs 早间预报是否有重大偏差？（温差 ≥5°C、新增降雨、极端天气）
- 如有偏差：给出明日穿搭调整建议

### 2. 一句话总结
用一句话概括今天的整体状态（结合干支五行、天气、用户当日活动）。

### 3. 明日预告
- 明日干支五行
- 明日天气趋势（如有显著变化则提醒）
- 明日穿搭主色预告（一句话）

## 输出格式

写入 `data/today.json` 的 `review` 字段：

```json
{
  "review": {
    "date": "2026-10-08",
    "generated_at": "2026-10-08T21:00:00+08:00",
    "summary": "癸丑土日，火气加持，文思泉涌的一天。",
    "weather_check": {
      "morning_forecast": "多云转晴 17-27°C",
      "actual": "晴 16-26°C",
      "deviation": "基本吻合，无需调整",
      "adjustment_needed": false
    },
    "outfit_review": "今日穿搭推送于 05:00 正常送达，火色系推荐与当日五行匹配。",
    "tomorrow_preview": {
      "ganzhi": "甲寅",
      "element": "木",
      "main_color": "火色系（木生火，喜神加持）",
      "weather_note": "气温小幅回升，注意防晒"
    }
  }
}
```
